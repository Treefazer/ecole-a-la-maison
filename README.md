# École à la maison

Application d'école à la maison pour le CP et le CE1 : programme de la semaine et de la journée, séances guidées qui s'adaptent aux bilans, notions à travailler, récompenses.

- Fonctionne hors ligne une fois ouverte.
- Les progrès restent sur chaque appareil (aucune donnée n'est envoyée en ligne). Pour passer d'un appareil à l'autre : menu ☰ → Suivi et export → Exporter, puis Importer sur l'autre appareil.

Installation : ouvrir la page puis « Installer l'application » (Chrome, Edge) ou « Partager → Sur l'écran d'accueil » (iPad, iPhone).
